# Noctura

Noctura is the redesigned version of the original CineStream frontend.

## What changed

- New Noctura name and visual identity
- Completely rebuilt modern visual system
- Four user-selectable themes: Aurora, Ember, Ocean, and Monochrome
- Theme choice is saved in localStorage
- Redesigned desktop and mobile navigation
- New landing page, cards, profile, forms, details, reviews, chat, and modal styling
- Responsive layouts for desktop, laptop, tablet, Mobile L, Mobile M, and Mobile S
- Existing routes, APIs, authentication, library features, TMDB integration, and backend functionality remain unchanged

## Run

```bash
npm install
npm run dev
```
