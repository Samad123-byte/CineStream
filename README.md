# 📖 About

CineStream is a **full-stack MERN movie discovery platform** that provides a modern streaming-inspired experience.

Users can create accounts, securely authenticate, discover thousands of movies through TMDB, save favorites, create watchlists, track viewing history, upload profile avatars, write reviews, watch trailers, and interact with an AI-powered movie assistant.

The project combines modern frontend architecture, REST APIs, authentication systems, cloud image storage, and AI integration to create a complete movie platform.

---

# Backend Setup

```bash
cd server

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret


# Cloudinary

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret


# TMDB

TMDB_API_KEY=your_tmdb_api_key


# AI

OPENROUTER_API_KEY=your_openrouter_api_key
```
